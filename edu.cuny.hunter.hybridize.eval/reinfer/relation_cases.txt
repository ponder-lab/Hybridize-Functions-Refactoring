# How a supplied signature relates to an inferred one, one case per line:
#
#   supplied ; inferred ; relation ; dtype relation ; shape relation
#
# A signature is its parameters' specs joined by " | ". A spec is dtype[dims], where a dim is an integer
# or None, `[]` is a scalar, `[*]` is unknown rank, `?` is the UNKNOWN dtype, and `(a, b)` is a sequence.
#
# The relation column is InputSignature.relate's own result, and InputSignatureTest asserts it against
# the Java order. The dtype and shape columns are the same order restricted to one axis; reinfer/test_spec.py
# asserts all three against the harness, and that dtype and shape combine to the relation.
